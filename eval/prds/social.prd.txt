Build a basic social-media web app in the current directory, with a Django backend and a React frontend.

Backend (in ./backend):
- Django + Django REST Framework, SQLite database.
- A Post model: id, author (short text), text (body), created_at (auto timestamp).
- REST endpoints:
  - GET /api/posts/  -> list all posts, newest first (JSON).
  - POST /api/posts/ -> create a post from {author, text} (JSON).
- A requirements.txt listing django and djangorestframework.
- Run the Django dev server and verify with curl that POST creates a post and GET lists it, before finishing.

Frontend (in ./frontend):
- A React app (Vite). A single page that:
  - fetches and lists posts (author, text, created_at), newest first.
  - has a form (author + text) that POSTs a new post, then refreshes the list.
- A package.json with the needed dependencies.

Top-level README.md: how to run the backend and the frontend.

Keep it minimal but working. Verify the backend API actually works before you finish.
