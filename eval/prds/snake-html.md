# Snake game in a single HTML file

Create a single self-contained file `index.html` that implements the classic
Snake game on an HTML5 `<canvas>`, with all CSS and JavaScript inline.

Requirements:
- Arrow keys steer the snake.
- The snake grows when it eats food; food respawns at a new random cell.
- The game ends when the snake hits a wall or itself.
- Show the current score.
- Everything must be inline — no external scripts, stylesheets, or CDNs.

It must open and play in a browser with no build step.
