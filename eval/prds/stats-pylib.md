# Statistics library in Python

Create a small Python module with tests, standard library only.

Create exactly two files:
- `stats.py` — with three functions:
  - `mean(nums)` — the arithmetic mean
  - `median(nums)` — the middle value (average of the two middle values for an
    even-length list)
  - `mode(nums)` — the most frequent value
- `test_stats.py` — a plain script (no pytest) that asserts a few cases and
  prints `all tests passed` at the end.

`python3 test_stats.py` must print `all tests passed`.
