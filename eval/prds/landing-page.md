# Responsive product landing page

Create a single self-contained file `index.html`: a modern, responsive landing
page for a fictional product, with all CSS inline in a `<style>` tag.

Requirements:
- A sticky or top navigation bar with links that jump to the sections below.
- Three sections with these exact ids: `id="hero"`, `id="features"`,
  `id="footer"`.
- The hero has a headline, subtext, and a call-to-action button.
- The features section shows at least three features.
- Believable real copy (a product name, real-sounding feature text) — no lorem
  ipsum.
- Responsive layout that works on mobile and desktop.

No external CSS frameworks or CDNs — style it yourself inline.
