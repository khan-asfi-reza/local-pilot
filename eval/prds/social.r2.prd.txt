Build a minimal Django REST API for posts, in the ./backend directory. Do NOT stop until all files exist and the API is verified.

Create these files, one write_file per file, before installing or running anything:
1. backend/requirements.txt  (django, djangorestframework)
2. backend/manage.py
3. backend/config/__init__.py
4. backend/config/settings.py  (INSTALLED_APPS includes rest_framework and posts; sqlite; ROOT_URLCONF config.urls)
5. backend/config/urls.py  (include posts.urls under /api/)
6. backend/posts/__init__.py
7. backend/posts/models.py  (Post: author CharField, text TextField, created_at auto_now_add)
8. backend/posts/serializers.py  (PostSerializer, all fields)
9. backend/posts/views.py  (list newest-first + create)
10. backend/posts/urls.py  (path 'posts/' -> the view)
11. backend/posts/apps.py and backend/posts/migrations/__init__.py

After ALL files exist: pip install -r requirements.txt, run `python manage.py makemigrations posts` and `migrate`, start the dev server with the serve tool on port 8000, then curl a POST to /api/posts/ and a GET to /api/posts/ to prove it works. Report the actual curl output.
